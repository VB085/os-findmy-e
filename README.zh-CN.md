# os-findmy-e — 增强版

基于 [sacca97/os-findmy-e](https://github.com/sacca97/os-findmy-e)（GPL-2.0）的
Android Find My 协议客户端。核心改动已提交上游 [PR #2](https://github.com/sacca97/os-findmy-e/pull/2)。

支持导入固定 P-224 密钥的第三方 Tag，并与滚动密钥配件共存。部分流程已使用
Android 14、arm64 设备和 DEONE MTAG 验证；尚未完成的验证列在下方。

## 当前功能

- **静态定位查询**：固定密钥使用 `acsnservice/fetch`，滚动密钥保留 v2 路径。
  同钥对照发现，静态接口可返回新的有效报告，而 v2 仍返回较旧报告。认证或服务器
  错误不再被当作“历史为空”。
- **电量格数**：近距离读取 `GVBAT`，按厂商四档状态显示，附采样时间，超过 12 小时
  标为过期。已移除猜测电压，不显示未经证实的精确百分比。
- **轨迹留存**：跨刷新合并去重，完整轨迹通过 Android Keystore 加密保存，重启或
  查询失败后恢复。每台配件最多保留近 90 天 / 1 万个点，最后已知位置持续保留；
  地图提供 6 小时至 90 天的查看窗口。
- **后台收集**：唯一 WorkManager 任务在联网时每 30 分钟尝试查询，flex 窗口为
  5 分钟；系统节电可能推迟。后台查询不连接蓝牙，也不轮换 Tag 密钥。
- **近距离工具**：响铃、读取电量、只读广播密钥核验，以及明确确认后的本地密钥管理。
  普通轮换校验已导入密钥；恢复模式需要操作者确认目标是自己有权管理的硬件。
- **账号与地图**：短信优先的双重认证、HTTP 401 后尝试续会话一次、中文界面资源、
  不含坐标的定位通知，以及使用自备 PMTiles 瓦片包的离线地图。

协议、存储及验证范围见 [静态 Tag 说明](docs/static-tags.md)。构建方法见
[Android 说明](app/README.md)和[原生库说明](native/README.md)。

## 验证范围与限制

已通过 235 项 Android JVM 测试、11 项 Rust 报告测试、3 项 Python 协议测试。
真机核对了静态定位查询、新的近距电量采样、轨迹加密落盘、重启恢复，以及
30 分钟周期任务的登记。

实体低电状态、跨地点移动与长期丢失寻物、无人值守会话续期，以及多个真实后台周期
仍需验证。刷新读取 Find My 网络的既有上报，不会生成实时位置，也无法补出缺失的
路线片段。近距离换钥不是丢失后的远程恢复手段，也不是频繁刷新定位的必要操作。

## 隐私与公开内容

仓库只发布源码和合成测试样本，不发布真实账号、会话凭据、Tag 密钥、坐标、抓包、
截图、本机设备状态、签名材料、APK 或 Apple CoreADI 镜像。蓝牙诊断日志保留计数和
状态，不记录设备地址或广播密钥标识。通知任务的最新位置快照仍为应用私有 JSON，
完整轨迹档案采用加密存储。
